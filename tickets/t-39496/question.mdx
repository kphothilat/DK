## Customer message

> Hi - we generate our OpenAPI spec as part of our CI pipeline, and Mintlify uses that spec to render our API reference. The problem is that Mintlify's deployment triggers immediately on push, before our spec generation job has finished. This means our API docs sometimes get deployed with a stale spec. Is there a way to delay or condition Mintlify's deployment so it only fires after our OpenAPI spec is ready?
