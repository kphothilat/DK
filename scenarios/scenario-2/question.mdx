## Customer problem

> Since last week, more than 50% of our normal weekly traffic came from just three San Francisco IP addresses over a single weekend. It's not our team. Did something change on your end?

## Context

- Mintlify did not make any changes that would explain this.
- Customer is a large enterprise running developer docs on Mintlify.
- To investigate, the following query was run against the analytics database (ClickHouse):

```sql
SELECT
    ip,
    count() AS views,
    uniq(path) AS unique_pages,
    min(created_at) AS first_seen,
    max(created_at) AS last_seen,
    any(user_agent) AS sample_ua
FROM events
WHERE subdomain = 'box'
  AND created_at >= toDateTime('2026-07-18 00:00:00')
  AND event = 'docs.content.view'
GROUP BY ip
ORDER BY views DESC
LIMIT 20
```
